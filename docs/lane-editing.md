# 车道线编辑与融合

## 修改已完成的车道线

进入「车道线标注」或「矢量地图」，在点云上点击折线，或在右侧列表选中它。
每个可见顶点显示编号圆柄，按住左键拖动即可修改该顶点的 XY；
该顶点的原始 Z 保持不变，坡道不会被压到统一地面高度。
需要改变高程时，在右侧顶点坐标中调整 Z。松开鼠标后可继续旋转、平移和缩放视角。

拖动操作修改实际标注文档，七路相机中可见的标注投影实时更新。
世界场景中的修改在整个 clip 共享；单帧模式只修改当前帧的 LiDAR 坐标标注。
点击「保存标注」后持久化，回放、重新加载及导出使用保存后的几何。
回放和标定期间不显示可编辑的车道线控制柄。

## 跨帧图像投影

在「整场景 4D」模式绘制的车道线始终保存为同一组世界坐标。
切换帧时，平台使用该帧当前注册位姿和该相机的有效投影矩阵重新计算像素，
旧地图缓存中的位姿不会覆盖更新后的注册位姿。
修改通用相机或 LiDAR 外参时，导入数据原有的逐帧投影矩阵也会同步更新，并保留各帧修正差异。
预建世界地图无需因此重复融合点云，原地图与标注坐标保持不变。

如果之前只保存了 frame-001 的投影修正，回到该帧并选择同一相机，打开「逐帧投影校准」，
点击「将当前修正应用整个 clip」。平台保存相机的相对修正，结合各帧自己的位姿和源标定生成投影，
不会把参考帧的绝对世界到相机矩阵直接复制到其他帧。随后可直接切帧或回放检查效果，无需重画车道线。
预建 4D 地图的新修正默认选择「整个 clip · 当前相机」，也可改为仅当前帧。

已有其他帧的独立精调优先保留；以后单独保存的逐帧修正也优先于整个 clip 的修正。
「清除整个 clip 修正」只清除共享修正，参考帧和其他帧已有的独立记录不删除。
只选择「仅当前帧」保存的修正仍只作用于指定帧和相机。
基础标定改变后，基于旧标定求解的本地配准记录会停用，需按新标定重新求解。

## 整理已有的重复线

1. 在车道线任务右侧点击「融合重复车道线」。世界场景模式处理当前整个场景，单帧模式处理当前帧。
2. 设置最大间距、最大方向差和最小重合长度，点击「预览融合」。
3. 点云和图像暂时显示融合结果；面板展示数量变化和各融合组的原始 ID。
4. 检查后点击「应用融合」，再点击「保存标注」。取消预览会恢复原来的显示；应用后、保存或继续编辑前可点击「撤销本次融合」。

预览与应用都不会直接写入后端标注。源标注、坐标模式、参数或 clip 改变时，旧预览失效；
异步请求不会把旧结果覆盖到新上下文。场景版本冲突时需重新加载后再预览。

## LATR 连续预标注

「应用候选时融合重复车道线」默认开启。每帧 LATR 返回 LiDAR 坐标折线，
平台先使用该帧实际配准位姿转换到世界坐标，再与已有场景车道线匹配。
重复 ID 会重新分配，避免覆盖已有人工标注。
已有的目标轨迹、图像区域和点语义标签保留；融合失败保留原标注与候选，可重试。
关闭该选项时独立追加候选，稍后也可手动预览融合。

跨帧结果应在默认「整场景 4D」模式应用；「单帧点云」的融合范围仅为当前帧。
自动融合仅处理包含本次候选的匹配组，不单独整理其他已有重复线。
自动融合后的「撤销本次融合」恢复候选和原线分开显示，保留本次新增的独立车道线。

## 当前相机的 clip 批量预标注

选择 clip 和需要处理的相机，在「预标注模型」中选择 LATR，设置权重、类别与置信度阈值，
点击「当前相机 · 批量预标注」。启动前会先保存已有修改。

- **全部图像**：处理当前相机在整个 clip 中的图像。例如 50 帧 clip，会依次处理这 50 帧。
- **指定数量**：设置起始帧、图像数量和抽帧间隔。起始帧按界面从 1 计数；
  起始帧 3、数量 4、间隔 2，会处理第 3、5、7、9 帧。
- 每帧只提交选定相机的图像与标定；不向 LATR 上传场景点云，也不同时启动几十次 GPU 推理。
  缺少该相机图像的帧会跳过，失败原因和成功 / 失败 / 跳过数量分别显示。

任务由后端保存并执行，关闭面板或刷新页面后可重新打开查看；历史任务也可切换查看。
取消将在当前正在推理的帧结束后停止后续帧，已经成功的结果保留。
「重试失败 / 未完成帧」继续同一个任务，只补跑失败或被取消、重启中断的帧；不会重跑成功帧。
服务重启不会声称任务已成功完成，而是保留成功结果并将中断任务标记为失败，之后可重试。

完成后点击「应用批量候选」，成功帧的折线按每帧实际配准位姿转换到世界坐标，
以独立候选加入场景草稿，随后打开融合面板。此流程不使用「单帧候选应用时融合」开关，
由你检查「预览融合 → 应用融合」的结果，再点击顶部「保存标注」。
例如相邻 50 帧都观察到同一段车道线，满足匹配阈值的重复折线会融合并延伸两端；
不同车道线仍保持独立。点云和当前相机的标注投影会同时更新。

批量推理不会覆盖现有目标框、图像区域或点语义标签；只有明确保存才写入最终标注。
应用和重试会检查图像、标定、注册位姿以及源帧和场景版本。
若任务期间修改并保存了这些数据，旧候选会被拒绝，需重新生成，避免把旧坐标结果加入新场景。

接口：`POST/GET /api/clips/{clip_id}/latr-batches`，
`GET /{job_id}`、`POST /{job_id}/cancel`、`POST /{job_id}/retry`、`GET /{job_id}/proposal`。
启动参数为 `camera_id`、可选 `frame_ids`、`label`、`score_threshold` 和 `weight_variant`；
省略 `frame_ids` 表示整个 clip。候选接口返回世界坐标折线，任务文件保存在被 Git 忽略的 `data/latr_batches/`。

## 匹配范围

默认阈值为三维间距 0.25 米、局部方向差 15 度、连续重合至少 1 米。
支持反向点序、部分重叠、曲线、坡道以及大数值世界坐标。
融合保留组内第一条折线的 ID 和重叠段原始几何，只用新观测延长两端，不平均移动已审核顶点。
类别必须相同，且仅处理开放的 `lane`、`lane_line`、`lane_marking`、`lane_solid`、`lane_dashed`；
闭合要素、交叉线、明显分叉及没有重叠证据的线段保留独立，不跨空白区域补线。

几何距离本身不能区分所有相邻标线。双实线等间距小于容差的同类标线可能被视为重复，
此时降低最大间距并检查预览；标定或车辆位姿存在偏差时，应先检查配准，避免提高容差后误合并。

## 预览接口

`POST /api/clips/{clip_id}/lanes/merge-preview` 接收：

```json
{
  "vectors": [],
  "max_distance": 0.25,
  "max_angle_degrees": 15,
  "min_overlap": 1.0,
  "scene_revision": 0
}
```

`vectors` 使用调用方选定的同一米制坐标空间；世界场景传入 `scene_revision` 检查保存版本，
单帧模式省略它。可选 `candidate_ids` 限制仅融合包含这些候选的组。
返回 `vectors` 与 `report`（输入数、输出数、移除的重复数及 `kept_id/source_ids` 融合记录）。
接口只计算候选，不创建场景标注文件或递增版本；保存仍使用原来的标注 PUT 接口。
