# Clip 标注回放

完成标注后点击顶部「回放标注」。存在未保存的框、车道线或点级标注时，先保存成功再进入回放。
有效的车道线绘制草稿可一并完成并保存；未完成的图像多边形及外参草稿需先完成、保存或还原。

回放从 clip 首帧开始，按采集时间戳播放；暂停后可继续，也可用上一帧、下一帧或时间轴逐帧检查。
支持 0.25×、0.5×、1×、2× 和循环回放。关闭循环时在最后一帧停下，再播放从首帧重来。
「退出回放」返回标注模式，并恢复原先的点云坐标视图、着色方式和地面筛选设置。

- 默认展示当前时刻完整扫描，按已注册位姿转换到世界坐标，显示当前轨迹框、全局车道线/矢量和源点语义标签。
  视点随车辆平移，保留手动选择的视角与缩放；跳帧会重新定位，避免长 clip 驶出当前观察范围。
- 可切换到整场景地图查看目标轨迹，七路图像继续与时间轴同步。过期或尚未生成的地图需先重建；
  当前扫描回放不依赖地图生成成功。
- 相机默认开启标注投影，同时显示当前帧图像多边形。场景标注与尚未迁移的单帧标注合并展示，避免重复绘制。
- 回放期间标注只读，可以转动、平移、缩放点云视角并放大相机图像，不能修改或运行预标注覆盖标签。

播放器只缓存当前及下一帧，预读完整点云、标注和七路图像并等待图像解码，准备好后一起切帧。
暂停或退出会取消未完成的切帧请求，避免暂停后仍因迟到响应继续跳帧。
数据来不及读取时显示缓冲并保持上一帧，不跳过待检查的帧。播放速度因此受网络、完整点云大小、
图像解码速度与浏览器性能影响；不会为追赶速度偷偷减少点数。缺失或读取失败的相机图像显示对应占位。
