# OmniLabel

面向自动驾驶 clip 的多传感器、多任务标注工作台。React / TypeScript / Three.js
前端与 FastAPI / NumPy 后端共享一套标定、坐标和标注格式，支持 7 路环视图像与激光点云。

平台使用 clip 级的 **4D 整场景工作区**，默认提供**合成数据**供操作和几何验证。
真实数据通过 JSON / ZIP 导入，不需要外部云账号。当前面向可信的单用户环境；
未提供登录、租户隔离或生产级权限管理，请在本机或受控内网使用。

## 启动

需要 Python 3.12+、Node.js 22+ 和支持 WebGL 的现代浏览器。

```bash
cd /workspace/OmniLabel
bash scripts/setup.sh
bash scripts/serve.sh
```

`setup.sh` 安装锁定的前后端依赖、构建前端并运行后端测试。
`serve.sh` 用同一个 8000 端口提供前端和 API，默认仅监听本机。
可信网络部署可设置 `OMNILABEL_HOST=0.0.0.0`；端口通过
`OMNILABEL_PORT` 配置。数据保存在被 Git 忽略的 `data/`，可通过
`OMNILABEL_DATA_DIR` 指定其他目录。程序首次启动生成演示 clip，之后保留用户标注。

开发时分别运行：

```bash
PYTHONPATH=backend .venv/bin/python -m uvicorn omnilabel.main:app --reload
npm run dev
```

Vite 将 `/api` 请求代理到后端的 8000 端口。

工作区可在 `data/workspace.json` 中设置 `default_clip_id`，或通过
`OMNILABEL_DEFAULT_CLIP` 环境变量指定默认场景。网址中的 `?clip=<clip_id>`
优先于默认设置，切换场景后网址会同步更新，便于直接打开指定结果。

## 标注流程

1. 选择示例 clip 或导入 clip JSON / ZIP，检查相机内参、外参和每帧位姿。
2. 导入后自动把整个 clip 重建为世界坐标地图；需要修正配准时选择 ICP 重建。时间轴切换相机和目标轨迹，地图保持不变。
3. 创建目标轨迹和全局矢量；选中框即显示「长±、宽±、高±」六面尺寸控制柄和中心移动柄，无需输入尺寸。切换旋转可调整航向。在任一时刻编辑动态目标会建立关键帧。
4. 左侧滚动相机栏实时显示框、车道线和地图标注投影。像素和点级任务可切到源帧；模型候选审核后应用并保存。
5. 导出 clip 标注及派生数据供审核或下游训练使用。

已完成的车道线可直接在点云中编辑：选中折线后拖动编号顶点，左侧相机投影实时更新，
拖动保持该点原有高度；需要改高程时仍可调整右侧 Z。
「融合重复车道线」支持可视预览、阈值设置、应用和保存前撤销；
LATR 候选默认先转换到当前场景坐标，再融合重叠车道线，保留其他任务标注。
选择 LATR 后，点击「当前相机 · 批量预标注」可运行整个 clip，或指定起始帧、图像数量和抽帧间隔。
批量任务在后台逐帧运行，支持取消、恢复查看和只重试失败 / 未执行帧；结果保留为独立世界坐标候选，
应用后再点击「预览融合 → 应用融合 → 保存标注」，将相邻图像中同一条车道线的重叠观测整合为完整折线。
详细操作及匹配范围见 [车道线编辑与融合](docs/lane-editing.md)。

震动导致同一 clip 各帧外参不一致时，可使用独立的逐帧、逐相机标定和六轴手动微调。
已接入 PJLab SensorsCalibration 的 CRLF 原生引擎，支持逐帧线特征掩码上传或自动提取命令；
运行环境、输入要求和操作见 [逐帧外参与 PJLab 标定](docs/pjlab-calibration.md)。

标注完成后点击顶部「回放标注」，自动保存后同步播放点云、七路图像及对应标注。
支持暂停、逐帧检查、0.25×–2× 倍速、循环播放，以及当前扫描/整场景地图切换；回放期间标注只读。
详细行为见 [Clip 标注回放](docs/clip-playback.md)。

「外参校准」可实时调整相机或 LiDAR 的 XYZ、Roll/Pitch/Yaw 修正量，预览标注与原始点云投影，
并保存或导出 JSON；原始标定自动备份。LiDAR 外参改变后需重建地图，详见[外参编辑](docs/calibration.md)。
新增「自动标定」可遍历全部帧和相机，调用 Koide 或内置 CPU 局部配准，
检查候选质量后批量保存，并导出包含相机内参、畸变和逐帧外参的 JSON。
保存结果同时用于原始点云和三维标注的图像投影；未通过的帧可进入「逐帧校准」补充对应点。
Koide 需部署真实运行环境；自动标定沿用已知相机内参并优化刚体外参，
部署、质量范围和保存路径见 [自动图像与点云标定](docs/koide-calibration.md)。
新增框和车道线保存支持 HTTP 局域网访问；地图未完成重建时也可使用当前帧的世界坐标扫描继续标注。

源扫描和场景地图不设置固定点数上限，默认全量显示；可选全分辨率、强度细节、实测表面和质心融合。
二进制点云兼容 Float32 与 Float64；世界坐标先减去显示原点，再转换为 GPU 浮点数，保留高精度地图细节。
多尺度 ICP 将扫描配准到局部子地图，并报告重叠率与误差。全量数据仍需要相应的内存、磁盘和显存；
大型场景可以使用连续分页或 NPY 下载，参见[重建与质量说明](docs/4d-scene.md)。

`bash scripts/serve.sh` 会校验前端源码与构建产物的内容指纹，拉取新代码后自动重建过期页面；
源码未变时直接启动。首次部署仍需运行 `bash scripts/setup.sh` 安装依赖，避免旧 `dist` 隐藏已更新的功能。

| 任务 | 当前能力 | 数据前提与范围 |
| --- | --- | --- |
| 3D / 4D 目标标注 | 框创建、拖动平移/缩放/旋转、跨时刻轨迹、关键帧和插值 | 静态世界状态或动态时间关键帧；不声称自动估计真实运动 |
| 4D 点云地图 | 全 clip 重建、位姿融合 / 实际 ICP、动态目标过滤、持久世界场景与轨迹 | ICP 需要重叠与有效几何；没有回环或全局 SLAM 优化 |
| 车道线 | BEV / 3D 折线绘制、顶点鼠标拖拽、重复线融合，或 LATR 三维候选 | LATR 可选择匹配的 ONCE / OpenLane 权重与配置，并需要真实标定和前视图像；融合结果需审核 |
| 矢量地图 | 世界坐标共享折线、多边形和类别；左侧相机同步投影 | 世界→活动 LiDAR 使用重建后的实际配准变换 |
| 图像语义分割 | 人工多边形、SAM2 正点/负点/框提示候选、掩码导出 | SAM2 需要远程模型配置与权重；类别由人工指定 |
| 点云语义分割 | 点选择 / 笔刷赋类与 CPU 地面候选 | 标签保持原点索引；地面候选需要审核 |
| OCC | CPU 观测占用/自由转换，或 OpenOccupancy 真实模型语义占用候选 | 两者分开标记来源；模型预测需人工审核，未返回区域保持 unknown |
| 标注结果投影 | 3D 框、车道线、矢量地图和图像区域实时投影；原始点云是可选图层 | 支持外参链、Brown 畸变、近面/画幅裁剪；已去畸变图像使用新 K 与零畸变 |

所有模型生成标注和几何候选都应经人工审核才能作为训练真值。
仓库已包含 SAM2、LATR、MMDetection3D、OpenOccupancy 的实际官方 API 推理适配器和部署脚本，
主平台不捆绑 GPU 运行时或权重。通过模型面板分别配置远程服务并检查真实加载状态；
协议、独立运行环境和 7 路相机适配限制见[模型接入说明](docs/model-worker.md)。
2080 / 12GB 本地服务器的独立安装、FP16 配置与云端连接步骤见 [SAM2 本地部署](docs/sam2-local.md)。
当前远程服务地址尚未提供，真实 checkpoint 推理仍需在目标 GPU 环境验收。
候选结果需要明确应用并另行保存，生成候选不会覆盖人工标注。

统一使用米、秒和弧度，右手 LiDAR / ego 坐标为 x 前、y 左、z 上；
相机光学坐标为 x 右、y 下、z 前。外参矩阵采用列向量。
投影变换为 `camera_from_ego @ lidar_to_ego @ p_lidar`，
地图变换为 `ego_to_world @ lidar_to_ego @ p_lidar`。

## 验证

```bash
PYTHONPATH=backend .venv/bin/python -m pytest
npm run build
npm run test:e2e
```

浏览器测试使用系统 Chromium；可用 `CHROMIUM_PATH` 指向已安装的可执行文件。
测试会在独立临时目录启动后端，不覆盖实际标注数据。

## 后续生产化

实际生产部署还需要：真实传感器样例验收、相机与激光雷达的时间同步策略、
百万点流式分块、多用户鉴权和审核流、对象存储、异步 GPU 队列、
模型版本与推理来源追溯、数据集导出适配器，以及备份和运行监控。
本仓库当前实现不将这些能力伪装成已部署服务。

MIT 许可证适用于本仓库原创代码。参考项目及模型权重各自遵循其许可证；
本实现未复制参考项目代码或捆绑权重。
